使用规则
1. 军种色不可混用。一份材料只讲一个军种时，主色只用该军种色；跨军种对比时才并列出现。
2. 军旗红与金星黄是"荣誉色"，不是装饰色。整份材料出现不宜超过 3–5 处，只给表彰、荣誉、核心结论。
3. 迷彩色只用于背景纹理，不用于文字。文字压在迷彩上会严重降低可读性，必须加半透明遮罩。
4. 指挥大屏走"深底 + 高亮"。背景 #0A0F14/#131C24， 数据点用雷达绿、数据青、琥珀、激光红，发光效果靠细描边与文字，不要大面积填充。
5. 状态色语义固定。红=敌方/威胁，蓝=友邻/我方，绿=安全/完成，黄=待确认，橙=警戒。 全单位统一，不允许按喜好换色。
6. 60-30-10 法则。底色占 60%，主色占 30%，标识色与状态色合计 10%。
