使用规则
1. 深度分层是骨干，不要打乱层级。越深越暗是硬规律， 图表里用同色系深浅表示水深，比用彩虹色科学得多，也不会有色觉障碍问题。
2. 温度/盐度这类"数值型"数据才用双色梯度。 低温 #2E6FB7 → 高温 #E85D3D，且必须配色标图例，否则读者无法反推数值。
3. 左红右绿不能互换。IALA A 区（我国采用）左侧标红、右侧标绿， 这是国际规则，用反了会造成实际航行风险。
4. 珊瑚橙、磷光青是高饱和点缀色。整屏出现 3–5 次封顶， 只给关键标记；大面积铺会显得廉价。
5. 深色大屏走"深海底 + 声呐青"。背景 #041622/#0A2436， 发光靠细描边与文字，不要大面积填充亮色。
6. 60-30-10 法则。底色 60%，主色 30%，点缀与状态色合计 10%。
