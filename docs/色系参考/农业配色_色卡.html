使用规则
1. 生长周期是一条时间轴，不要跳色。播种褐 → 出苗嫩绿 → 拔节青绿 → 抽穗深绿 → 灌浆黄绿 → 成熟金黄 → 收获褐，首尾同色系形成闭环。做长势监测时按这个序列走，读者一眼能判断处于哪个阶段。
2. NDVI 必须用标准分级，不能自创。8 级分级已按国际通用区间设定， 且必须在图旁给出完整色标，否则无法从颜色反推植被覆盖度。
3. 长势与灾情要分开两套色。长势是好/中/差（绿/黄/红）， 灾情是旱/涝/病虫等类型（各有专属色），不要混用同一组红黄绿，否则"长势差"和"病虫害"会分不清。
4. 金黄系（稻穗、麦浪、油菜花）是点缀色不是主色。 大面积铺会显得俗气且刺眼，整屏 3–5 处封顶。
5. 深色大屏走"深绿底 + 新芽高亮"。背景 #0E1A12/#16261C， 高亮用 #A3E635，发光靠细描边与文字，不要大面积填充。
6. 60-30-10 法则。底色 60%，主色 30%，点缀与状态色合计 10%。
