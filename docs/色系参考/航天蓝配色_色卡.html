使用规则
1. 主色不出三支。页面主色只用酞青蓝、航天蓝两支，天蓝只做点缀，否则会花。
2. 中国红是"警报"，不是装饰。整站出现不超过 5 处，只给要闻标签、重要提示、告警。
3. 深底配白字，浅底配深字。色卡上每个色块都标了建议文字色，按标注来不会错。
4. 层级靠"同色系深浅"。卡片 #EEF4FA → 描边 #BEC3C8 → 标题 #0F3D75，比堆颜色高级。
5. 投影环境别用浅灰字。墨黑系浅于 50%（#8C8C8C）在投影上会糊。
6. 60-30-10 法则。浅底/白占 60%，主色占 30%，天蓝与中国红合计 10%。
